# Corona-Statistic

A Next.js dashboard showing **current COVID-19 statistics for Germany** — cases, deaths,
7-day incidence and vaccinations — broken down by **federal state (Bundesland)**, by
**district / independent city (Landkreis)**, and down to individual detail pages.

It is a Russian-language re-creation of the German site **Corona-in-Zahlen.de**, built as a
school / olympiad project. The UI is in Russian; the data is real and updates daily from a
public API.

## Tech stack

- **Next.js 13** (App Router) — server components, ISR
- **React 18** + **TypeScript**
- **Tailwind CSS 3** (+ PostCSS / Autoprefixer)
- **ESLint** (`eslint-config-next`)

## Data source

All statistics come from the public **[Corona-in-Zahlen](https://corona-in-zahlen.de) API**:

- `https://api.corona-zahlen.org/germany`
- `https://api.corona-zahlen.org/states` and `/vaccinations/states`
- `https://api.corona-zahlen.org/districts`
- `https://api.corona-zahlen.org/vaccinations`

The figures are based on **Robert Koch Institute (RKI)** data (and, in upstream sources,
Johns Hopkins University, WHO and Our World in Data). Requests are cached with
`revalidate: 10` (a page is refreshed from the API at most every 10 seconds). One component
also queries the German Wikipedia API (`de.wikipedia.org/w/api.php`) for supplementary text.

**Disclaimer:** the numbers are taken as-is from third-party sources and depend on testing
volume and reporting delays. They are provided without any guarantee of correctness or
timeliness.

## Pages

| Route | Description |
| --- | --- |
| `/` | Landing page — intro and links into the statistics |
| `/bundeslander` | Table of all 16 federal states: search, sortable columns, top-3 lists |
| `/bundeslander/[name]` | Detail page for one federal state |
| `/state-statistic` | Table of all cities and districts (400+) with search and sorting |
| `/state-statistic/[name]` | Detail page for one city / district |
| `/landkreis-uebersicht` | A–Z index of every district, linking to its detail page |

## Getting started

Requires **Node.js 18+**.

```bash
npm install

npm run dev     # start dev server → http://localhost:3000
npm run build   # production build
npm start       # run the production build
npm run lint    # ESLint
```

The dev server fetches live data from `api.corona-zahlen.org`, so it needs network access.

## Notes & known limitations

This is an old personal/school project, kept mostly for history. Be aware of:

- **Route slugs are generated by naive character replacement.** German umlauts and `ß` are
  transliterated in URLs (`ü→u`, `ö→o`, `ä→a`, `ß→b`), and the detail pages look names up the
  same way. The replacement rules are not fully consistent between where links are *built* and
  where they are *resolved*, so some detail-page links can 404 or mismatch.
- **Some copy is hard-coded**, including figures pasted into explanatory paragraphs, so it can
  drift from the live API values.
- **Leftover dependencies** — `translate` and `wikijs` are declared but not clearly used; they
  look like experiments from the original build.
- **Russian comments and rough edges** remain throughout the source.
